# 🌤️ Weather App

A responsive weather application built with React, TypeScript, and Vite.

## Features

- 🔎 Search for cities around the world
- 🌤️ Current weather conditions
- 📅 7-day weather forecast
- 🌡️ Celsius and Fahrenheit
- 📍 Use current location
- 🕘 Recent searches
- 💾 Local storage
- 🌙 Dark mode
- ⏳ Loading states
- ❌ Error handling
- 📱 Responsive design

## Built With

- React
- TypeScript
- Vite
- Open-Meteo API
- CSS
